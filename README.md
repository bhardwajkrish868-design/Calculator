# 🧮 Calculator Suite

### Java Desktop Application

**Calculator Suite** is a Java-based desktop application that combines multiple calculation tools into a single, easy-to-use platform. The application is developed using **Java Swing** with a clean graphical user interface and modular structure.

It is designed to provide students and everyday users with quick access to essential mathematical and academic calculation tools.

---

## 📌 Project Overview

Calculator Suite provides a centralized dashboard from which users can launch different calculator modules.

The current application includes:

* **Basic Calculator** – Everyday arithmetic calculations
* **Scientific Calculator** – Advanced mathematical operations
* **CGPA Calculator** – Credit and grade-based CGPA calculation
* **Dashboard** – Central navigation with application information and live date/time
* **Splash Screen** – Application startup interface

The project focuses on combining functionality with a simple and modern desktop user interface.

## ▶️ Running the Project

Make sure **Java JDK** is installed.

```bash
git clone https://github.com/bhardwajkrish868-design/Calculator.git
```

Open the project in VS Code and navigate to the source directory:

```bash
cd Calculator-Suite-VSCode/src
```

Compile:

```bash
javac *.java
```

Run:

```bash
java Main
```

## 🎓 CGPA Calculation

The CGPA module uses a credit-weighted calculation:

```text
CGPA = Σ(Credit × Grade Point) / Σ(Credits)
```

The application can use the following grade-point system:

| Grade | Point |
| :---: | :---: |
|   O   |   10  |
|   E   |   9   |
|   A   |   8   |
|   B   |   7   |
|   C   |   6   |
|   D   |   5   |
|   F   |   0   |
